LUNA WANDER & DAWN BRINGER — FINAL WEBSITE

This is the final static website package for the comic project.

IMPORTANT:
- Keep index.html, episode-01.html, css/, js/, and assets/ in the same structure.
- Episode 01 is a real clickable story page: episode-01.html.
- The homepage Episode 01 card and story/archive entry link to the reader.
- The old geometric placeholder SVG artwork has been removed.
- All visible character/story artwork now uses the anime PNG assets.
- Dawn is consistently referred to with she/her pronouns.

GITHUB PAGES:
1. Create a GitHub repository.
2. Upload the CONTENTS of this folder, not the ZIP itself.
3. Make sure index.html is at the top level of the repository.
4. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
5. Wait for GitHub Pages to publish the site.

The site is plain HTML/CSS/JavaScript and does not require a build step.
